# v9cli

The customer command-line interface for [Valid9](https://www.valid9.com).

Read requirements, tests and release context, prepare drafts, and import
supported source documents using your own Valid9 account and permissions.
Reviews, signatures and release publication remain in the Valid9 app.

## Installation status

The first public release is being prepared. Downloads and Homebrew
installation will be enabled after Mac signing, notarization and installation
checks are complete. There is no public binary to install yet.

Planned platforms: macOS (Apple Silicon and Intel), Linux (ARM64 and x86-64).

- [CLI documentation](https://www.valid9.com/docs/cli/)
- [Release downloads](https://github.com/valid9d/v9cli/releases)
- [Valid9 Homebrew tap](https://github.com/valid9d/homebrew-tap)
- Support: hello@valid9.com

## About this repository

This repository holds customer downloads and release notes. The application
source is maintained separately and remains private. Releases include
checksums and third-party license notices. Never post passwords, tokens,
session files or private workspace records in public issues.
